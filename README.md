# 🌌 GalaxyOS Launcher

Un launcher Android sperimentale ispirato allo stile Samsung One UI, progettato per offrire una schermata Home moderna e personalizzabile.

## ✨ Funzionalità

- 🕒 Orologio e data in italiano
- 🔎 Ricerca delle applicazioni installate
- 📱 Icone delle app con apertura rapida
- 📌 Dock per le applicazioni preferite
- ✋ Gesto a due dita per aprire il menu di personalizzazione
- 🖼️ Accesso alla scelta dello sfondo
- ⚙️ Collegamento alle impostazioni della schermata Home

## 📱 Compatibilità

Progetto in fase sperimentale, sviluppato e testato inizialmente con un emulatore Android e uno Xiaomi Redmi 10C.

La compatibilità può variare in base alla versione di Android e alle personalizzazioni del produttore.

## 🚧 Stato del progetto

GalaxyOS Launcher è attualmente in sviluppo. Alcune funzionalità potrebbero essere incomplete o richiedere ulteriori test.

## 🛠️ Sviluppo

Il progetto utilizza Java e Gradle con Android SDK.

## 📦 Installazione

Quando sarà disponibile una versione APK, potrai scaricarla dalla sezione **Releases** di questo repository.

Per installare una versione di prova:
1. Scarica il file APK.
2. Autorizza l'installazione dell'app, se Android lo richiede.
3. Apri GalaxyOS Launcher.
4. Se lo desideri, selezionalo come applicazione Home predefinita dalle impostazioni Android.

Installa APK soltanto da fonti di cui ti fidi.
